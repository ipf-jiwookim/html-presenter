# 슬라이드 앵커 노트 · 내보내기/가져오기 · 발표 편의 기능 — 설계

날짜: 2026-08-18 · 대상: `index.html` (단일 파일 유지) · 상태: 사용자 승인 대기

## 배경과 목표

같은 발표를 다른 강의장(다른 PC 포함)에서 다시 하는 상황을 지원한다.
핵심 문제 두 가지:

1. 노트가 페이지 **번호**에 묶여 있어, 덱 중간에 한 장을 끼우면 뒤 노트가 전부 밀린다.
2. 노트가 브라우저 안에만 있어, 다른 PC로 가져갈 방법이 없다.

해결 원칙: **로그인·서버·클라우드 없음.** 노트는 슬라이드 "내용"에 붙이고,
이동은 사람이 읽을 수 있는 마크다운 파일로 한다.
절대 규칙: **틀린 자리에 조용히 붙느니 미배정으로 남긴다.**

## 범위 (이번 라운드에 전부 포함)

| # | 항목 |
|---|---|
| 1 | 슬라이드 앵커 3종 세트 (지문 생성 + 중복 순번 + 기존 노트 마이그레이션) |
| 2 | 노트 .md 내보내기 / 가져오기 왕복 (드롭존 확장자 분기, 충돌 정책, 미배정 노트함) |
| 3 | 무반응 덱 · 분리형 이미지 안내 2종 |
| 4 | 큐 시트 글씨 크기 A−/A+ · 타이머 목표 시간(남은 시간 표시) |

제외(변경 없음): 로그인, 클라우드 동기화, 패키지 HTML, 유사도(fuzzy) 자동 매칭, 병합 편집기.

## 1. 슬라이드 앵커

### 1-1. 지문(anchor) 생성 — `slideAnchor(el, occurrenceMap)`

입력: 슬라이드 엘리먼트. 출력: `"a3f9c1"` 또는 중복 시 `"a3f9c1#2"`.

절차:

1. `el.textContent`로 보이는 텍스트 추출
2. **공통 토큰 제거**: 덱의 모든 슬라이드에 등장하는 줄/토큰(푸터, 브랜드 문구,
   "AI 깐부 · SHOWCASE" 류)을 제거한다. 구현: 각 슬라이드의 토큰 집합을 만들고
   전체 슬라이드의 80% 이상에 나타나는 토큰을 스톱워드로 삼는다.
3. **숫자 토큰 제거**: `P.07 / 21` 같은 페이지 카운터가 총장수 변화로 전 슬라이드
   지문을 무효화하는 것을 막는다. 숫자·숫자 조합 토큰(`07`, `7/21`, `2026.07.23`)을 통째로 버린다.
4. 공백 정규화(연속 공백→1, trim) 후 소문자화
5. 32비트 FNV-1a 해시 → 6자리 hex (외부 라이브러리 없음, 동기 실행 —
   `crypto.subtle`은 비동기라 쓰지 않는다)
6. 결과가 빈 문자열(이미지뿐인 장)이면 지문은 `"empty"` — 중복 순번으로만 구분
7. 같은 지문의 n번째(2 이상) 등장이면 `#n`을 붙인다 (문서 순서 기준)

주의: 지문 계산은 `deckState()`가 슬라이드 목록을 찾은 그 selector의 엘리먼트들로 한다.
`deckState()`가 구조를 못 찾는 덱(§1-4)은 앵커 대상이 아니다.

### 1-2. 저장 키 구조

```
ptnotes2:{deckName}          → JSON 한 덩어리
{
  "anchors": { "a3f9c1": "노트…", "a3f9c1#2": "…", … },
  "byIndex": { "0": "…", … },        // 구조 없는 덱 폴백
  "orphans": [ { "text": "…", "hint": "8 / 22 · 제목…" }, … ],
  "fontSize": 16,                      // §4-1
  "goalMin": 45                        // §4-2 (미설정 시 없음)
}
```

- 읽기/쓰기는 현재의 `store`(localStorage + 메모리 폴백) 경유. 덱당 키 1개로 통합해
  키 스캔 없이 전체 로드/저장한다.
- 노트 저장(oninput)은 현재 페이지의 앵커 키에 기록. 앵커가 없으면 `byIndex`에 기록.

### 1-3. 기존 노트 마이그레이션

첫 로드 때 `ptnotes2:{deckName}`이 없고 구키 `ptnotes:{deckName}:{n}`이 있으면:

- 구조 있는 덱: n번째 슬라이드의 앵커를 계산해 `anchors`로 이관
- 구조 없는 덱: `byIndex`로 이관
- 이관 후 구키는 삭제하지 않는다 (롤백 안전판, 용량 무시 가능 수준)

### 1-4. 폴백 규칙

`deckState()`가 null인 덱(클래스 없는 인라인 토글류)은 앵커 없이 `byIndex`로만 동작한다.
이 경우 가져오기에서 페이지 수가 다르면 자동 배정하지 않고 전부 미배정함으로 보낸다.

## 2. 내보내기 / 가져오기

### 2-1. 내보내기 — 큐 시트 헤더의 [내보내기] ghost 버튼

파일명: `YYYY-MM-DD_{덱이름(확장자 제거)}_노트.md` · 다운로드는 Blob + `<a download>`.

```markdown
# AI깐부_쇼케이스_발표자료.html — 발표 노트
<!-- html-presenter notes v1 · deck: {덱지문} · 21페이지 · 2026-08-18 -->

## 8 / 21 · "다섯 스킬이 PDF에서 쓰는 데이터"
<!-- slide: 7c1a9f -->
여기서 질문 받기. 시간 넘치면 생략.
```

- 슬라이드 제목 = 해당 장 텍스트의 첫 줄(40자 컷). 사람이 읽는 용도.
- `deck:` 은 덱 전체 지문(전 슬라이드 앵커 연결의 해시) — 가져올 때 "다른 자료" 경고용.
- 노트가 있는 페이지만 기록. 미배정 노트는 `## 미배정` 섹션으로 함께 내보낸다.
- 빈 노트뿐이면 버튼은 비활성화하고 툴팁으로 이유를 보여준다.

### 2-2. 가져오기 — 별도 버튼 없음, 드롭존/파일선택이 확장자로 분기

- `.html/.htm` → 덱 로드(현행), `.md` → 노트 가져오기
- 덱이 로드되기 전에 .md를 넣으면: "발표 자료를 먼저 열어주세요" flash
- 파싱: `<!-- slide: … -->` 주석의 앵커만 신뢰. 페이지 번호는 무시(참고용이므로)
- `## 미배정` 섹션의 노트는 그대로 미배정 노트함으로 들어간다
- v1 헤더가 없는 .md는 거부하고 안내 flash ("이 파일은 노트 내보내기 파일이 아닙니다")

배정 규칙 (순서대로):

1. 앵커가 현재 덱에 존재 → 그 슬라이드에 배정
2. 앵커 불일치 → **미배정 노트함**으로
3. `deck:` 지문이 다르면 배정 전에 확인: "다른 자료에서 내보낸 노트입니다. 계속할까요?"

충돌 정책 — 같은 슬라이드에 기존 노트(비어 있지 않고 내용이 다름)가 있으면:

- 건수를 세어 한 번만 묻는다: "N개 페이지에 이미 다른 노트가 있습니다 —
  [파일 것으로 교체] [기존 유지]" (페이지별 개별 선택은 만들지 않는다)
- 완료 flash: "노트 21개 중 20개 연결, 1개는 미배정 노트함에 있습니다."

### 2-3. 미배정 노트함

큐 시트 아래 접이식(`<details>`) 목록. 항목당:

- 원래 위치 힌트(`8 / 22 · "제목…"`) + 노트 앞부분
- **[이 페이지에 붙이기]** — 현재 보고 있는 페이지의 앵커(없으면 인덱스)로 이동,
  대상에 기존 노트가 있으면 덮지 않고 뒤에 이어 붙인다(`\n\n` 구분)
- [삭제]
- 함이 비면 섹션 자체를 숨긴다. 미배정 노트도 `store`에 저장되어 새로고침에 살아남는다.

## 3. 안내 2종 (조용한 실패 제거)

### 3-1. 무반응 덱

이동 판정(`moved`)이 이미 있으므로: 사용자의 **첫 [다음]**이 `moved=false`이고
`deckState()`도 null이며 스크롤 폴백도 못 움직였을 때 1회만 안내 배너:

> 이 자료는 키보드 넘김에 반응하지 않는 것 같습니다. 자료를 만든 AI에게
> "← → 방향키로 슬라이드가 넘어가게 해줘"라고 요청해 보세요.

(마지막 장 도달의 `moved=false`와 구분: step===0 && 구조 없음일 때만.)

### 3-2. 분리형 이미지

덱 로드 시 `deckHTML`에서 상대경로 `<img src>`(‘http’, ‘data:’, ‘//’로 시작하지 않는 src)를
발견하면 1회 flash:

> 이미지가 별도 파일로 분리된 자료입니다 — 단일 HTML로 합쳐야 이미지가 표시됩니다.

## 4. 발표 편의

### 4-1. 큐 시트 글씨 크기

큐 시트 헤더에 `A−` `A+` ghost 버튼. 13→16→20→24→28px 5단계, 덱별 저장(`fontSize`).
textarea와 다음 노트 미리보기에 함께 적용.

### 4-2. 타이머 목표 시간

- 경과 시간 클릭 → 분 단위 `<input inputmode="numeric">` 인라인 편집 (모달 없음)
- 설정되면 "경과" 계측 옆에 "남은" 계측 추가: `goalMin*60 − 경과`
- 남은 시간 5분 이하 → 앰버(--next), 0 이하 → `−MM:SS`로 계속 표시 + 라이브 레드
- 덱별 저장(`goalMin`), 리셋(↺)은 경과만 초기화하고 목표는 유지
- 미설정이면 현재와 완전히 동일한 화면

## 데이터 흐름 요약

```
덱 로드 → deckState 로 슬라이드 목록 → 전 슬라이드 앵커 일괄 계산(공통토큰/숫자 제거)
        → ptnotes2 로드(없으면 구키 마이그레이션) → 페이지 이동 시 앵커로 노트 읽기/쓰기

내보내기: anchors+orphans → md 텍스트 → Blob 다운로드
가져오기: md 파싱 → 앵커 대조 → 배정/충돌질문/미배정함 → store 저장
```

## 오류 처리 원칙

- 앵커 계산 실패(예외)는 전부 `byIndex` 폴백으로 흡수 — 콘솔이 죽는 일은 없다
- 가져오기 파싱 실패는 flash 안내 후 무시 (기존 노트 불변)
- localStorage 실패는 기존 `store` 메모리 폴백이 흡수

## 테스트 계획 (브라우저 패널 + __ptLoad)

1. **삽입 시나리오(핵심)**: 21장 덱에 노트 3개 → 8번 앞에 새 장 삽입한 수정본 로드
   → 3개 노트가 제자리(밀리지 않음), 새 장만 빈 노트
2. 푸터 오염: `P.07/21` 스타일 푸터를 가진 덱에서 1 실행 — 총장수 변화에도 앵커 불변
3. 중복 장: 같은 내용 2장 각각 다른 노트 → 새로고침 후 유지
4. 마이그레이션: 구키만 있는 상태에서 로드 → 노트 보임
5. 왕복: 내보내기 → localStorage 비우기 → 가져오기 → 전체 복원
6. 수정 덱 가져오기: 한 장 고친 덱에 가져오기 → 그 장만 미배정함, [이 페이지에 붙이기] 동작
7. 충돌: 다른 내용의 기존 노트 위에 가져오기 → 질문 1회, 교체/유지 각각 확인
8. 무반응 덱 안내, 분리형 이미지 안내, A−/A+, 목표 타이머(5분 앰버·초과 표시)
9. 회귀: 마지막 장 정지, 미리보기 +1, 재동기화, 청중 창 독립 창 열림(실 Chrome)
